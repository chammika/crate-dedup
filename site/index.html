crate-dedup

Crates whose outdated dependency makes the ecosystem compile two copies of the same crate, ranked by how much one upgrade would help. Expand a row for the reasoning.

How the score works

Affected: crates whose dependency tree contains the crate to upgrade and the dependency's latest line, so they compile the dependency twice. Sole: affected crates where this crate is the only one holding the old line, so upgrading it removes the duplicate entirely. Impact = Σ over affected crates of (their downloads in the last 90 days ÷ number of crates holding the same old line in their tree). Only normal, non-optional dependencies of each crate's latest version are counted.
